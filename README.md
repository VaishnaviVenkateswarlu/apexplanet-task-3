# Daily Knowledge Hub

## About the Project
Daily Knowledge Hub is a responsive website developed for the ApexPlanet 45-Day Web Development Internship - Task 3.

It allows users to test their knowledge through an interactive quiz and discover interesting facts using a public API.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Public REST API

## Features
- Interactive multiple-choice quiz
- Instant answer feedback
- Quiz score tracking
- Restart quiz option
- Interesting facts fetched dynamically from a public API
- Responsive design for desktop, tablet, and mobile devices

## How to Run
1. Download the project files.
2. Open index.html in a web browser.
3. Answer the quiz questions.
4. Click Discover a Fact to load an interesting fact.
